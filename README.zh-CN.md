# 续桌

给你的工作现场存档，像游戏一样，下次一键继续。

原生 macOS 桌面工作存档工具。启动后在屏幕顶部常驻一枚小胶囊，点击就能在原处保存现场、继续工作或留下收工记录；需要整理资料时再打开存档画廊。每张卡收好相关文件、网页、支持的窗口位置和「下一步」；资料保留在原处。无需账号，本地保存，没有上传服务。MIT 开源。

0.3.0 重新设计桌面岛与应用图标，采用受 Liquid Glass 启发的透明层次、柔和高光和紧凑布局。支持简体中文 / English 即时切换，语言偏好会在下次启动时保留；用户的项目名称、备注和文件名保持原文。日常面板保持小巧，输入时向下展开；保存和收工按钮固定在底部。

设计参考与查阅范围见 [DESIGN_REFERENCES.md](docs/DESIGN_REFERENCES.md)。界面与图标均独立实现，没有复制第三方源码或资源。

胶囊是续桌自己的悬浮面板，不修改系统桌面，也不替换 Apple 灵动岛。运行时不显示 Dock 图标，菜单栏保留「续桌」入口。

## 使用

1. 打开 `output/续桌-macOS.zip`，把「续桌.app」拖入「应用程序」。需要 macOS 14 或更新版本；本次构建面向 Apple Silicon（arm64）。
2. 启动后点击屏幕顶部的胶囊，在展开面板里选择「保存现场」，为当前工作起名，写下下一步。可添加文件、文件夹和网页。
3. 回来后点击胶囊，选择一张存档，再点「继续现场」；续桌会重新打开资料，并尝试恢复支持的窗口布局。下一步提醒就在面板里。
4. 收工前在面板中写一句进度。需要整理、拖入更多资料或导出交接包时，选择「管理存档」。
5. 按住胶囊顶部中央可拖动位置，点击同一处可展开或收起。找不到时，在菜单栏「续桌」中选择「展开续桌岛」「显示续桌岛」或「移回屏幕顶部」；从同一菜单退出。

展开桌面岛后，可在顶部用「中 / EN」快捷切换；也可在「设置」的语言选项或菜单栏的「语言 / Language」子菜单中选择「简体中文」或「English」。桌面岛、管理画廊、设置、菜单、恢复提示与导出资料包文案跟随所选语言；macOS 自己的文件选择器按钮与权限对话框仍由系统语言决定。

首次打开的三张卡是示例，示例文案随界面语言切换。用「保存现场」建立自己的存档。

当前版本需要手动启动，还没有登录自动启动选项。旧版存档会继续使用同一处本地数据。

这是本地开发签名版本，未经过 Apple 公证。若 macOS 拦截，先尝试右键 App →「打开」；需要时到「系统设置 → 隐私与安全性」确认允许打开。

## 首版恢复范围

| 资料 | 实现范围 |
| --- | --- |
| 网页 | 手动添加或拖入 HTTP/HTTPS 链接，由默认浏览器重新打开；勾选读取标签页时，支持当前运行的 Safari 和 Google Chrome。 |
| 文件和文件夹 | 选择或拖入资料，记录原位置与系统书签；用默认应用打开文件、Finder 打开文件夹。不会从窗口标题推断原文件路径。 |
| 窗口布局 | 「辅助功能」授权后，记录应用暴露的普通窗口。按应用及完全相同的规范化窗口标题匹配，尝试恢复位置和大小。跳过隐藏应用、最小化、全屏及无标题窗口；多个同名窗口无法区分时跳过并说明。 |
| 桌面缩略图 | 「屏幕录制」授权后捕获主显示器，排除续桌自身窗口；没有截图时，桌面岛显示项目图标，管理画廊显示明确标注的布局示意。 |
| 备注与收工记录 | 本地保存「下一步」和历次收工备注。 |

权限在 App 设置中按需开启。「自动化」由 macOS 在读取浏览器标签页时询问；「辅助功能」用于窗口位置；「屏幕录制」用于桌面缩略图。未授权时仍可保存和打开手动加入的资料及备注。

首版不保存未保存文档、应用内部编辑状态、浏览器标签归组或标签所属窗口。应用是否允许调整窗口、窗口能否以原标题重新打开，会影响布局恢复；断开的显示器上的窗口会调整到当前屏幕可见区域。

## 本地存储

存档 JSON 与桌面缩略图位于 `~/Library/Application Support/XuZhuo/`。添加和删除卡片不会移动或删除原文件。资料包包含网页清单、备注和可选的文件副本；未复制的资料可能保留本机路径，分享前检查包内内容。

## 构建与验证

运行需要 macOS 14 或更新版本；从源码编译需要 Xcode 26 或更新版本及其 macOS SDK，因为新系统玻璃效果使用 macOS 26 的原生 glassEffect API。Swift Package 使用 Swift 5 语言模式；旧系统在运行时使用兼容材质。没有第三方依赖。

```sh
swift test
./scripts/build-app.sh
open output/续桌.app
```

打包脚本生成图标、Release 可执行程序、`续桌.app`、`续桌-macOS.zip` 和 `续桌-源码.zip`，并进行本地 ad-hoc 签名与签名校验。没有开发者证书或公证步骤。图标来自 `scripts/create-icon.swift` 的本地绘制。

存储测试检查重启后的进度、资料去重、损坏存档保护、保存失败后的数据与缩略图保留、重试去重、导出副本与原文件保留、缺失资料报告、网页清单转义，以及符号链接和递归目录保护。

恢复测试检查空现场、缺失文件和无效链接；不打开其它应用或申请权限。未授权截图的降级测试在测试进程已有录屏权限时跳过。

桌面岛位置测试检查展开与收起时保持顶部、越界拖动、负坐标外接屏、显示器断开、无效位置和尺寸，以及较小显示器上的可见性。本轮自动测试 28 项，其中 27 项通过、1 项因测试进程已有录屏权限而主动跳过，0 失败。语言测试检查偏好持久化、未知语言回退，以及英文展示不改写用户内容或示例存档。

0.3.0 已在真实 macOS 桌面验证启动仅显示胶囊、点击展开为 480 × 340 的横向面板，以及顶部「中 / EN」切换：窗口标题、项目示例、下一步、操作按钮、底部入口和菜单同步变为英文。新图标和系统支持的原生玻璃控件已实际显示。

本轮尚未完成保存、收工、继续现场与重启的完整实机回归；相关存储、恢复失败报告和语言持久化由上述自动测试覆盖。跨桌面、全屏和授权后的窗口布局恢复尚未实机验收。
